# Communication-CNA

Repo de travail pour la communication digitale de **Cellard Notaires & Avocats**.
Pilote : François Cellard. Hub Notion : [📣 Communication — CNA](https://www.notion.so/34f86f63adb581808265efbed2667aff).

## 📁 Contenu de ce repo

### `article-photos-cna/`
Dossier dédié à la **direction artistique des images d'articles juridiques**.

#### Scripts Python de génération
- `build_neoclassic.py` — direction néoclassique (sceau, bouclier, globe, temple)
- `build_matiere.py` — direction matière (cordes, orbe, arche, strates)
- `build_finary_style.py` — direction Finary-inspired (sablier, boussole, clé, sceau)
- `build_bleu_lumiere.py` — direction « Lumière notariale » (bleu lumineux + or)
- `build_rubans_bleus.py` — direction « Rubans bleus » (abstraite, ton sur ton, inspirée du nœud existant)
- `build_final.py` — rendus définitifs charte matière (supersampling 2×)

#### Sous-dossiers (chaque charte produit ses PNG 1280×720)
- `prototypes-charte/` — 3 premiers protos minimalistes (mono / fil parallèles / arbre)
- `charte-v2-neoclassique/` — sceau notarial, bouclier, globe filaire, temple néoclassique
- `charte-v3-matiere/` — cordes marine, orbe pétrole, arche minuit, strates carbone
- `charte-FINAL/` — rendus haute qualité matière (orbe, cordes globe, strates, cordes)
- `charte-FINARY-STYLE/` — sablier ivoire, boussole sable, clé gris perle, sceau cire
- `charte-LUMIERE-NOTARIALE/` — sablier azur, boussole paon, clé ciel, sceau glace
- `charte-RUBANS-BLEUS/` — nœud royal, spirale azur, anneaux océan, pyramide saphir
